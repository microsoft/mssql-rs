# mssql-python-rs

Rust-based native runtime for the [`mssql-python`](https://github.com/microsoft/mssql-python)
driver. This distribution ships the `mssql_py_core` extension — the TDS core and the
bundled ODBC driver (`mssqlodbc`) — as prebuilt platform wheels.

It is an implementation dependency of `mssql-python` and is not intended to be used
directly.
